# Schnellstart: Projektleitung

Legen Sie ein Projekt an, genehmigen Sie Zeit und erstellen Sie einen Leistungsnachweis. Anmeldung: siehe Schnellstart für Mitarbeiter.

Die Oberfläche gibt es auf Bosnisch und Englisch. Die deutschen Bezeichnungen hier sind Übersetzungen.

## Projekt anlegen

1. Öffnen Sie **Projekte** und wählen Sie **Neues Projekt**.
2. Geben Sie den **Namen** ein und wählen Sie den **Kunden**. Kunde fehlt? Fragen Sie das Controlling.
3. Wählen Sie das **Abrechnungsmodell**. Nur **Nach Aufwand** und **Gemischt** lassen sich aus Zeit abrechnen.
4. Füllen Sie **Beginn**, **Ende** und **Budget (Stunden)** aus, wenn bekannt.
5. Legen Sie **Warnung ab (%)** fest: Ab diesem Anteil zeigt das Projekt **Budget fast verbraucht**.
6. Prüfen Sie die **Währung** und wählen Sie **Speichern**. Sie leiten nun das Projekt.

Verträge erfasst das Controlling. Fragen Sie danach, bevor Sie sie Arbeitspaketen zuordnen.

## Arbeitspakete planen

1. Öffnen Sie das Projekt. Wählen Sie unter **Arbeitspakete** **Neues Arbeitspaket**.
2. Geben Sie den **Namen** ein. Mit **Teil von** ordnen Sie das Paket einem anderen unter.
3. Wählen Sie bei Bedarf **Vertrag** und **Leistungskategorie**.
4. Geben Sie **Geplante Stunden** ein. Schalten Sie **Abrechenbar** aus, wenn Sie die Arbeit nicht berechnen.
5. Wählen Sie **Speichern**.
6. Ordnen Sie Pakete mit den Pfeilen: **Nach oben**, **Nach unten**, **Unter das Paket darüber**, **Eine Ebene höher**.
7. Paket fertig? Wählen Sie **Arbeitspaket bearbeiten**, setzen Sie **Status** auf **Geschlossen** und wählen Sie **Speichern**.

## Team zusammenstellen

1. Wählen Sie unter **Team** die **Person** und die **Projektrolle**.
2. Wählen Sie **Mitglied** für Personen, die Zeit buchen. Wählen Sie **Hinzufügen**.
3. Jemand scheidet aus? Wählen Sie **Entfernen** neben dem Namen.

Personen brauchen zuerst ein Konto. Die Administration lädt sie ein.

## Zeit genehmigen

1. Öffnen Sie **Zeit genehmigen**. Hier steht eingereichte Zeit Ihrer Projekte, nie die eigene.
2. Wählen Sie Einträge oder nutzen Sie das Kästchen im Tabellenkopf (**Alle auswählen**).
3. Alles in Ordnung? Wählen Sie **Genehmigen**.
4. Etwas stimmt nicht? Wählen Sie die Einträge, geben Sie einen **Grund** ein und wählen Sie **Zurückgeben**. Die Person wird benachrichtigt.

Genehmigte Zeit ändert sich nie. Korrekturen bucht das Controlling.

## Leistungsnachweis erstellen

1. Öffnen Sie **Leistungsnachweise** und wählen Sie **Neuer Nachweis**.
2. Wählen Sie **Projekt** und Zeitraum mit **Von** und **Bis**. Der letzte Monat ist vorgeschlagen.
3. Wählen Sie **Erstellen**. Der Nachweis enthält nur genehmigte Zeit.
4. Eine Meldung nennt nicht genehmigte Einträge des Zeitraums. Genehmigen Sie sie und erstellen Sie einen neuen Nachweis.
5. Laden Sie ihn als **PDF**, **XLSX** oder **CSV** herunter.

Ein Nachweis ändert sich nie. Die Option **Mit Beträgen** ist für das Controlling.

## Budget beobachten

1. Öffnen Sie **Projekte** und sehen Sie auf **Zustand**: **Gut**, **Budget fast verbraucht** oder **Über Budget**.
2. Öffnen Sie ein Projekt, um die gebuchten Stunden je Arbeitspaket zu sehen.
