# Schnellstart: Mitarbeiter

Buchen Sie Ihre Woche und reichen Sie sie ein. Sie brauchen ein Konto und einen Platz im Team eines Projekts.

Die Bezeichnungen in der Oberfläche können leicht abweichen.

## Passwort festlegen

1. Öffnen Sie den Link in der E-Mail zum Zurücksetzen des Passworts. Er gilt 60 Minuten.
2. Geben Sie zweimal ein langes Passwort ein und wählen Sie **Passwort zurücksetzen**.
3. Geben Sie E-Mail-Adresse und Passwort ein und wählen Sie **Anmelden**.
4. Link abgelaufen? Wählen Sie auf der Anmeldeseite **Passwort vergessen?** und fordern Sie einen neuen an.

## Zwei-Faktor-Anmeldung einschalten

1. Öffnen Sie das Menü mit Ihrem Namen, dann **Einstellungen** > **Sicherheit**.
2. Bestätigen Sie mit Ihrem Passwort, wenn danach gefragt wird.
3. Wählen Sie **2FA einschalten**.
4. Scannen Sie den QR-Code mit Ihrer Authenticator-App oder kopieren Sie den Schlüssel. Wählen Sie **Weiter**.
5. Geben Sie den sechsstelligen Code ein und wählen Sie **Bestätigen**.
6. Speichern Sie die **2FA-Wiederherstellungscodes** in einem Passwortmanager. Sie erscheinen nur einmal.

## Woche buchen

1. Öffnen Sie **Zeiterfassung**. Jede Zeile ist ein Arbeitspaket, jede Spalte ein Tag.
2. Zeile fehlt? Wählen Sie sie unter **Arbeitspaket hinzufügen**. Das Feld erscheint bei vielen Paketen.
3. Klicken Sie in eine Zelle und tippen Sie die Zeit: `1:30`, `1,5` und `1.5` sind eineinhalb Stunden.
4. Drücken Sie Tab oder eine Pfeiltaste. Jede Zelle wird sofort gespeichert.
5. Beschreiben Sie die Arbeit im Feld **Beschreibung** unter der Tabelle. Ihre Firma kann das verlangen.
6. Falscher Wert? Wählen Sie **Rückgängig** für die letzte Änderung oder leeren Sie die Zelle.

| Taste | Wirkung |
|---|---|
| Pfeil hoch, Pfeil runter | Vorige oder nächste Zeile |
| Enter | Nächste Zeile |
| Pfeil links, Pfeil rechts | Voriger oder nächster Tag, vom Anfang oder Ende des Textes |
| Tab | Nächstes Feld |

Eine rote Summe markiert einen langen Tag. Ein Tag nimmt nie mehr als 24 Stunden auf, ein gesperrter Monat keine Zeit.

## Timer nutzen

1. Wählen Sie über der Tabelle ein **Arbeitspaket**, dann **Timer starten**.
2. Ergänzen Sie am Ende eine **Beschreibung** und wählen Sie **Stoppen und buchen**. Volle Minuten kommen in die Zelle des Tages.
3. Über Mitternacht erhält jeder Tag seinen Teil.
4. Versehentlich gestartet? Wählen Sie **Verwerfen**. Es wird nichts gebucht.

## Einreichen

1. Prüfen Sie die Woche. Wechseln Sie mit **Vorige Woche**, **Diese Woche** und **Nächste Woche**.
2. Wählen Sie **Woche einreichen**.
3. Eingereichte und genehmigte Zeit steht grau unter der Zelle. Sie ist nicht mehr änderbar.

## Zurückgegebene Einträge

1. Sie erhalten eine Benachrichtigung mit dem Grund. Die Zelle ist rot umrandet.
2. Klicken Sie in die Zelle. Unter der Tabelle steht **Zurückgegeben:** mit dem Grund.
3. Korrigieren Sie Zeit oder **Beschreibung** und wählen Sie erneut **Woche einreichen**.

Genehmigte Zeit falsch? Sagen Sie es dem Controlling. Dort wird eine Korrektur gebucht.
